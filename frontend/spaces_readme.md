# AgriGuard — Interactive Demo

**AI-Powered Pest Detection and Community Outbreak Early Warning for Rwandan Smallholder Farmers**

## About AgriGuard

AgriGuard helps Rwandan smallholder farmers identify crop pests and diseases, receive outbreak warnings, and connect with agricultural support — through a smartphone app available in **English and Kinyarwanda**.

This Space hosts a **static web build** of the AgriGuard React Native (Expo) frontend. It runs entirely in your browser as an interactive demonstration using sample data.

> **Demo Mode** is active. All data shown is fictional sample data created for demonstration purposes. No real farmer records, AI predictions, or outbreak events are represented.

---

## How to Use the Demo

1. Click **Explore Interactive Demo** on the welcome screen — no account required.
2. Navigate using the bottom tab bar: **Home**, **Reports**, **Ask AI**, **Alerts**, **Advice**, **Profile**.
3. Try the full report flow: select a crop → describe symptoms → submit → see AI result.
4. Ask a crop question in the **Ask AgriGuard** tab (try: *"How do I treat Fall Armyworm?"*).
5. View sample outbreak alerts and risk scores in the **Alerts** tab.
6. Browse farming guidance in the **Advice** tab.
7. Switch between **English** and **Kinyarwanda** using the language toggle on any screen.

## Demo Data Notice

All sample data in this demonstration:
- Is fictional. No real farmers, real locations, or real outbreak events are represented.
- Is clearly labelled with "(Sample)" or the demo mode banner.
- Does not reflect current or historical agricultural conditions in Rwanda.
- Is not generated by a connected AI model — results are pre-defined sample outputs.

For the full live system with real AI analysis, the backend and AI service must be deployed separately.
